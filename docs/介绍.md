# 介绍

整个系统的架构如下
runtime：唯一执行层；runtime：唯一执行层；人与关于pack的操作都基于这一层进行操作，设计写盘/回滚
runner / registry：门禁模块，run/publish 用；registry 依赖 runner，runner 依赖 runtime。
hub / market / launcher / serve：不同外壳，各自只依赖 kernel(+runtime)；它们不复制安装逻辑，只是把同一计划/同一状态换个出口。
