### PACK-01 清单与 Schema
- PACK-01.1 ◆ 元数据：名称/scope/版本/描述/许可/作者/主页/关键词。缺必填即拒；未知字段拒绝。`[有]`

- PACK-01.4 ◆ 接线：`provides / needs / slots / bindings / dependsOn`。`needs` 只查提供方，不排序。`[有]`
- PACK-01.5 ◆ 覆盖：`overrides`（改 pin/参数）与 `overlays`（文件层，最后盖）。两类冲突的报错级别不同。`[有]`
- PACK-01.6 ◆ 安装期脚本：`install.exec` 与 `undo`。exec 默认待批准，undo 只记录不自动跑。`[有]`
- PACK-01.7 ◆ 验证声明：`file-exists / config-key / command / mcp-ready / knowledge-integrity / scenario`。`[有]`
- PACK-01.8 ◆ 持久状态：`state` 块声明目录与 `retain`；`${state.x}` 可插值。`[有]`
- PACK-01.9 ◆ 继承与组合：`extends`（本地/远程）、`composition.order / env`。`[有]`（远程父包安装期解析 `[部分]`）
- PACK-01.10 ◆ 可见性与分发：`public / unlisted / internal / private`，默认 private。`[有]`
- PACK-01.11 ◆ 格式版本：`packhub.dev/v0`；未知主版本读方必须拒绝。`[有]`
- PACK-01.12 ◆ 作者侧约束声明：资源最小 Harness 版本、必需特性（如「需要 hook 支持」）。`[无]`
