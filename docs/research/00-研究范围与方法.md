## 2. 边界口径

| 层 | 归谁 | 举例 |
|---|---|---|
| Pack 定义、组合、验证、发布 | PackHub Core | manifest、plan、lock、verify、registry |
| 安装、实例、启动、修复、卸载 | Launcher | 实例目录、运行时、进程、端口、快照 |
| 能力映射与转换 | Adapter | skill 目录映射、MCP 配置格式、指令文件、能力降级 |
| Agent 循环、推理、上下文、工具执行 | Harness（P5） | 不实现，只识别与适配 |

判据：一条功能如果去掉 Pack / 实例 / Harness 适配任一个词仍然成立，它大概率属于 P5，不进清单。

## 3. 研究对象清单

### A 类：Minecraft 启动器与整合包体系

| 项目 | 为什么选它 | 证据级别 |
|---|---|---|
| PCL / PCL2 | 中文用户最多，交互范式（实例列表 + 一键装 + 崩溃分析）是直接参照 | 中：官方帮助文档与长期使用认知，未逐条读源码 |
| Prism Launcher | 跨平台、实例隔离与组件管理做得最细 | 中：文档与使用认知 |
| HMCL | 中文、跨平台、整合包导入链路完整 | 中：文档与使用认知 |
| Modrinth App | 与内容站同源，Pack 分发与更新模型清楚 | 中：文档与使用认知 |
| CurseForge App | 商业化整合包分发的事实标准（manifest.json） | 中：格式公开，客户端未核对 |

### B 类：Agent 专用启动器

| 项目 | 定位 | 证据级别 |
|---|---|---|
| PCL-DSH | PCL 二创，剥离 MC，改为装配与多实例管理 dsh | 高：README 全文已读 |
| Codex Dream Skin | 不改官方包，用 CDP 注入给 Codex 桌面端换主题，主题包有清单/校验/回滚 | 高：README 全文已读 |
| 其他 Codex 启动器 | 搜索结果里多为单点工具（皮肤、快捷方式），未发现完整启动器 | 中：GitHub 检索 1 次，受 API 限额影响未穷尽 |
