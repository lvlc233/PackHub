# PackHub 全系统细化审计

> 日期：2026-11-05 ／ 口径：34 个 CLI 子命令、全部 `<cmd> --help`、源码入口、219 项测试、示例包与 registry 实测。
> 目的：找出“像创作台只有草稿却标完成”这类**功能面存在但端到端没走通**的漏项，而不是复述 README。

## 结论

- 功能清单里已没有 `[todo]` / `[part]`，但**清单本身仍然按“有这条命令/有这张表”验收**，不保证端到端。
- 本次审计实际找到 **30 个漏项/不一致**：本轮修掉 10 个，剩下 21 个按严重度排进待办。
- 最严重的三类：**CLI 参数被静默忽略**、**发布/初始化组合起来必然失败**、**状态/配置损坏时直接抛堆栈**。

## 审计方法（可复现）

```bash
pnpm check
pnpm ui:audit
for c in $(packhub --help | ...); do packhub $c --help; done
pnpm packhub plan examples/code-review
pnpm registry:verify-all
# 手工：init → lock → run → publish；损坏 state.json 后 uninstall；未知 --flag；plan --index
```
