# 复盘（作为一个学习动作）

复盘是重新审视已有经历，从中发现新的理解、问题或可能性。

可以回顾事件、还原过程、分析原因、比较预期与结果、反思判断、寻找规律，也可以重新解释过去的经历。根据实际情况选择和组合这些能力。

## 可以从哪些角度复盘

- **事件：** 发生了什么，当时有哪些条件和信息。
- **过程：** 做了哪些选择，为什么这样做，还有哪些可能的做法。
- **结果：** 实际发生了什么，与预期有哪些差异。
- **原因：** 哪些因素影响了结果，哪些解释仍需验证。
- **认知：** 原来的理解是否发生变化，发现了什么新问题。
- **迁移：** 这些经验可能在哪些其他情境中有用。
- **改进：** 是否需要调整已有判断、方法、工具或行为。

这些是可选择的观察角度，不是必须依次完成的步骤，也不要求每次全部覆盖。

## 复盘结果

复盘可能产生新的理解、经验、疑问、方法、行为调整，也可能发现原有判断仍然成立。

有价值的发现可以根据需要记录、修改已有资料或转化为可复用的能力，不要求每次复盘都产生文件改动。

## 约束

- 区分实际发生的事件、自己的解释和未经验证的猜想。
- 不把单次经历直接当作普遍规律。
- 不为完成复盘而强行寻找错误、原因或改进项。
- 不要求复盘一定产生新结论或行动。
