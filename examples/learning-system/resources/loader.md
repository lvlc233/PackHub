# 学习系统的加载器

这个包只带框架：两个 skill 和这份说明。记忆区里已有的内容不随包走——那是本机攒下来的，换台机器应该是空的。

## 装完要做的三件事

1. 填配置。skill 里说的 `config.md` 是一份键固定、值随机器变的文件：

   ```yaml
   - memory:          # 记忆区根目录
   - memory_fallback: # 没有 memory 时用它；两个都空就什么都不写
   - memory_strategy: # 什么值得记的判据
   - note_to:         # 这一轮学习的临时笔记，用完删
   - learning_module: # 以前想过怎么学的地方，卡住时看
   ```

   空值的意思是「这里没有默认」，不替你猜。

2. 建记忆区的入口索引。宿主读用户目录下的 `AGENTS.md` 当全局说明，里面至少要有：记忆放在哪、动手前读哪份领域文件、跑命令前读哪份环境记录。没有这份索引，记忆区的文件在开工时不会被读到。

3. 要「到点自己复盘」，在宿主里挂一条每日提醒，指向 `memory-core/references/review.md`。

## 两个 skill 各管什么

- `learn-core`：学一个东西，把它变成下次能用的认识。不规定学完产出什么形状。
- `memory-core`：判断什么值得记、记成什么形态、下次怎么被找回来。不管怎么学。

两者是分化关系，不是依赖：可以只装一个。

## 已知的机器绑定

两个 `SKILL.md` 里写着打包那台机器上的绝对路径。换机器后这行指空：要么改这两行，要么把配置文件放回同一个路径。这是把框架打出来时才看见的——skill 的正文没有跟着包走。
