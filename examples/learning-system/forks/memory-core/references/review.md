# 自复盘

提醒到点会叫我。叫了不一定有活；看一眼再决定做不做，别为了让提醒显得有用而改东西。

## 先看

这一段时间记忆区里哪些文件变过（`git log -- data/learnning` 能直接给），哪些碰都没碰过。变过的是判断还是措辞——只动措辞的那几次，通常说明当时没有新东西，只是在让它看起来像有。

再想一件这里查不到的事：最近哪次真任务里，有判断被现实打回来了。

## 增

一条判断只有在真任务里撞过才从 `[候选]` 升格；撞法是它给的动作真的改了结果，不是事后觉得它说得对。

新学到的那句先去找它该改写的那一句。找不到落点才新增；两句并排存着，下次只会挑顺眼的那句用。

## 退

退不等于当初写错了。三种情况都该退：被后来的事推翻；被更准的说法替掉；绑定的版本或平台变了、前提已经不成立。

退的方式按代价从轻到重：改写、合并、标成过时、删。删之前先看有没有别处引用它——引用断掉比留着一条旧话更坏。

## 做完

只说改了哪句、退了哪条。没有可做的时候回一句"这轮没有"就结束，不补一条来交差。

复盘的要求是让下一次开工少犯一次，不是让记忆区看起来在运转。
